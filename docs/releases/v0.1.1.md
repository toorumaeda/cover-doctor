**Pre-release (0.1.1) — experimental.** Unofficial. Verified on one setup only.

## What's new in 0.1.1
- **New app icon.** Nothing else changed in the Mac app: its code is the same as 0.1.0.
- **First Windows version** (`CoverDoctor-0.1.1-Windows-x64.zip`), with the same steps and safety checks as the Mac app.
- The Mac zip was built on a GitHub-hosted Apple Silicon Mac by the repository's workflow (`.github/workflows/build-macos.yml`) instead of on the author's Mac. The libraries are built from the same official source tarballs.

Cover Doctor fixes the problem where the Music app on your iPhone shows **another album's cover** (or a wrong playlist cover) after syncing music from a Mac. It replaces the cover image files that the iPhone uses with the correct images found in your song files. It never changes the Music database, your songs, or your Mac's library, and it saves the images it replaces so you can undo.

## Download
- `CoverDoctor-0.1.1-macOS-arm64.zip` — for **Apple Silicon Macs** (macOS 14 or later; see below).
- Check the download with the SHA-256 file next to it: `shasum -a 256 CoverDoctor-0.1.1-macOS-arm64.zip`.
- `CoverDoctor-0.1.1-Windows-x64.zip` — for **Windows 10/11 (64-bit)** with iTunes or the Apple Devices app. Verified on Windows 11 only. See [windows/README.md](https://github.com/toorumaeda/cover-doctor/blob/main/windows/README.md) (Japanese) and the `README.txt` inside the zip.

## Before you use it
- **macOS will block the first launch** (the app is not signed with an Apple Developer ID). You only need to allow it once; step-by-step instructions with screenshots are in the [README](https://github.com/toorumaeda/cover-doctor#opening-the-app-for-the-first-time-macos-warning).
- **Use at your own risk.** It writes to a private area of your iPhone's media storage. Undo is built in, but this is an early version.
- **Verified only on:** macOS 27.0.1 (Apple Silicon), one iPhone with iOS 27.0, about 8,500 songs and 700 albums (with 0.1.0, which has the same code). It is built to run on macOS 14 or later, but that has **not** been tested. Other iOS versions and Intel Macs are not supported or not verified. The Windows version was verified on one Windows 11 PC with the same iPhone.
- Albums whose songs have no embedded cover image cannot be fixed. A later sync can bring wrong covers back; just diagnose and fix again.

**プレリリース（0.1.1）— 試験的な公開です。** 非公式です。動作確認は、1つの環境だけです。

## 0.1.1 の変更点
- **アプリのアイコンを新しくしました。** Mac 版は、ほかは変わっていません（コードは 0.1.0 と同じです）。
- **Windows 版を初めて公開します**（`CoverDoctor-0.1.1-Windows-x64.zip`）。Mac 版と同じ流れ・同じ安全装置です。
- Mac 版の zip は、作者の Mac ではなく、リポジトリの手順書（`.github/workflows/build-macos.yml`）で、GitHub が用意する Apple Silicon の Mac 上でビルドしました。ライブラリは、同じ公式のソースから作っています。

Cover Doctor は、Mac から iPhone に音楽を同期したあと、iPhone のミュージックで**別のアルバムのジャケット**（またはプレイリストの誤ったカバー）が表示される問題を直します。iPhone が使っているジャケット画像のファイルを、曲ファイルに入っている正しい画像で置き換えます。ミュージックのデータベース、曲ファイル、Mac のライブラリは、変更しません。置き換える前の画像を保存するので、元に戻せます。

## ダウンロード
- `CoverDoctor-0.1.1-macOS-arm64.zip` — **Apple Silicon の Mac 用**（macOS 14 以上。下を参照）。
- 横の SHA-256 のファイルで、ダウンロードを確認できます: `shasum -a 256 CoverDoctor-0.1.1-macOS-arm64.zip`
- `CoverDoctor-0.1.1-Windows-x64.zip` — **Windows 10/11（64ビット）用**。iTunes か「Apple デバイス」アプリが必要です。確認は Windows 11 のみです。詳しくは [windows/README.md](https://github.com/toorumaeda/cover-doctor/blob/main/windows/README.md) と、zip の中の `README.txt` を見てください。

## ご利用の前に
- **初回の起動は、macOS に止められます**（Apple の開発元 ID で署名していないためです）。許可は1回だけで済みます。画像付きの手順は、[README](https://github.com/toorumaeda/cover-doctor#opening-the-app-for-the-first-time-macos-warning) にあります。
- **自己責任でお使いください。** iPhone のメディア保管領域の、内部の部分に書き込みます。「元に戻す」は付いていますが、初期版です。
- **動作確認ができているのは:** macOS 27.0.1（Apple Silicon）、iOS 27.0 の iPhone 1台、約8,500曲・700アルバムだけです（コードが同じ 0.1.0 で確認）。macOS 14 以上で動くように作っていますが、**試していません**。ほかの iOS のバージョン、Intel Mac は、対応していない、または、確認していません。Windows 版は、Windows 11 の PC 1台と、同じ iPhone で確認しました。
- 曲にジャケット画像が入っていないアルバムは、直せません。あとで同期すると、誤りが戻ることがあります。その場合は、もう一度、診断して直してください。
