# App icon

`icon-1254.png` is the full-size artwork. The two pictures the doctor holds were drawn as SVG (`classical.svg` left, `metal.svg` right), rendered to PNG at 1200×1200 with Chromium, and placed into the base artwork `base-1254.png` by `compose.py` (run it in this folder after rendering the SVGs to `classical.png` and `metal.png`) (perspective-warped into each picture frame, keeping the hands and badges).
The Windows files `src/CoverDoctor.App/AppIcon.ico` (16–256 px) and `AppIcon.png` (128 px, window icon) are made from `icon-1254.png` with the outside made transparent.
