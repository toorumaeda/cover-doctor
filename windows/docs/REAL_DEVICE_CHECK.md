# 実機での確認（1回分のまとめ）

Windows の PC と iPhone を、1回つないで確かめることの一覧です。**1〜5 は読み取りだけ**で、iPhone は変わりません。**6 以降（書き込み）は、始める前に必ず承認をいただきます。**
所要時間の目安: 診断は、初回が約 6 分、2 回目以降が約 3 分でした（2026-10-19、アルバム 515 件の iPhone で実測。初回は曲を取り出すため長い。途中で外しても、もう一度「診断する」を押せば、取り出し済みの分は飛ばして続きから進みます）。

## 0. 準備（iPhone なしでできます）
1. `CoverDoctor-0.1.0-test4-Windows-x64.zip` を、デスクトップなどに**フォルダごと**解凍します。
2. 次の3つを控えてください（README の「確認した環境」に、実際の値で書くためです）。
   - Windows のバージョン: キーボードの Windows キー + R →「winver」→ OK。表示された「バージョン」と「OS ビルド」。
   - iTunes か「Apple デバイス」アプリのどちらが入っているか、とその版（設定 → アプリ → インストールされているアプリ で「iTunes」「Apple Devices」「Apple Mobile Device Support」を探す）。
   - iPhone の iOS のバージョン（iPhone の 設定 → 一般 → 情報）。

## 1. 通信の入口の確認（読み取りのみ）
iPhone を USB でつなぎ、ロックを解除して、「このコンピュータを信頼」が出たら「信頼」を選びます。
エクスプローラーで、解凍したフォルダ（`CoverDoctor.exe` がある所）を開き、上のアドレス欄に `powershell` と入力して Enter（そのフォルダで PowerShell が開きます。デスクトップが OneDrive の中にある PC でも、この方法なら場所を気にせずに済みます）。次を貼り付けて Enter:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check_amds.ps1
```

表示された行を、そのまま貼り付けて送ってください（端末の ID は先頭4文字だけ、信頼の記録は「読めたかどうか」と大きさだけが出ます。中身は出ません）。
- 期待する結果: `ListDevices: OK, 1 device(s)` と `ReadPairRecord (....): OK, ... bytes`。

## 2. アプリの起動と、初回の警告
1. `CoverDoctor.exe` をダブルクリックします。
2. 「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」**。この2枚の画面を、スクリーンショット（Windows キー + Shift + S）で撮っておいてください（README に載せる画像です）。
3. 「はじめに」の画面が出ます。これも撮って、「了解して使う」を押します。

## 3. 接続の表示
画面の上に「（iPhone の名前）（iOS 〇〇）に接続中」と緑の丸が出ることを確認します。
- 「補助ツールが Apple Mobile Device Support に接続できません」と出る場合は、そのまま知らせてください（1. の結果と合わせて原因を調べます）。

## 4. 診断（読み取りのみ）
「診断する」を押します。終わったら、画面（件数と一覧）を撮ってください。
- Mac 版ですでに直したあとなら、「直せる」は 0 件のはずです。

## 5. 結果の報告（名前は出ません）
同じ PowerShell の画面で、次を貼り付けて Enter:

```powershell
.\CoverDoctor.exe report | Out-String
```

出てきた内容（件数と、見た目の距離の分布）を送ってください。しきい値 70 が、実機の画像でも妥当かの判断に使います（docs/THRESHOLD.md）。

## 6. 修復と「元に戻す」（書き込み。**ここで一度止めて、承認をいただきます**）
Mac 版ですでに直してあると、Windows 版で直すものがありません。書き込みまで確かめるには、次のどちらかが必要です。
- 試験用の入れ替え（テスト版 `0.1.0-testN` だけにあるコマンド。正式版には入っていない）: `.\CoverDoctor.exe testswap --count 10 --yes | Out-String` で、「正しい」アルバムを10件、わざと隣のアルバムの画像にします（上書きの前の画像は、診断のときに PC に保存済み）。そのあと 診断 → 直す → 元に戻す を確かめます。うまく戻らないときは `.\CoverDoctor.exe testswap-undo --yes | Out-String` で、保存した画像に戻します。
- A. Mac 版で「元に戻す」をしてから（誤ったジャケットに戻る）、Windows 版で 診断 → 直す → iPhone のミュージックで見た目を確認 → 「元に戻す」→ もう一度 直す。
- B. 次にまた誤りが出たときに、Windows 版で直す。

確認すること: 直したアルバムが、ミュージックアプリを開き直したあとに正しい絵になっているか／「元に戻す」で元の状態に戻るか／再診断で「直せる」が 0 件になるか。

## 送っていただきたいもの（まとめ）
- 0. の3つの値
- 1. と 5. の表示
- 2.〜4. のスクリーンショット
- 6. を行った場合は、その結果
